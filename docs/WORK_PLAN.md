## Что делать в ожидании

- **Р1:** пишет заготовку `RecommendationEngine` на заглушке индекса, настраивает `flake8` и `black`, проверяет PR.
- **Р2:** после передачи данных пишет unit-тесты для загрузчика и препроцессора, расширяет тестовые запросы.
- **Р3:** пока Р2 чистит данные, пробует модели SentenceTransformers на маленьком примере и готовит скрипт бенчмарка.
- **Р4:** с первой недели пишет каркас `Evaluator` на фиктивных данных, структуру отчёта и README, макет интерфейса.

## Правило передачи этапа

Этап считается переданным, когда выполнены три условия:

1. Pull Request слит в `dev`.
2. В Issue написан комментарий «готово» с примером запуска кода.
3. Следующий в цепочке подтвердил, что всё запускается у него.
